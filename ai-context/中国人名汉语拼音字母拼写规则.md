## 1　范围

本标准规定了使用汉语拼音字母拼写中国人名（包括汉语人名和少数民族语人名）的规则。

本标准适用于文化教育、编辑出版、中文信息处理及其他方面的姓名拼写。

## 3　术语和定义

下列术语和定义适用于本文件。

### 3.1　单姓　mono-character surname

汉语中只有一个字的姓，如张、王、刘。

### 3.2　复姓　multi-character surname

汉语中不止一个字的姓，如欧阳、司马、端木。

### 3.3　双姓　double-character surname

汉语中由两个单姓组合而成、用于人名拼写的姓，如郑李、项斯。

## 4　总则

中国人名包括汉语人名和少数民族语人名。汉语人名的拼写形式一部分来自现代汉语的普通话语音，一部分来自特定的人名形式（包括字、号、笔名、艺名、法名、帝王名号等），凡专称性的形式均依习惯而定。少数民族语人名依照该民族语的语音和习惯拼写形式拼写。

## 5　拼写规则

### 5.1　汉语人名拼写规则

#### 5.1.1

正式的汉语人名大小写、连写、分连写的规则为：姓和名分写，姓在前，名在后，姓和名的首字母都大写，姓和名之间留空。例如：

| 拼音         | 汉字     |
| ------------ | -------- |
| Wáng Fāng    | 王芳     |
| Mǎ Běnzhái   | 马本斋   |
| Ōuyáng Wén   | 欧阳文   |
| Lǚ Lüè       | 吕略     |
| Yáng Wéimín  | 杨为民   |
| Luó Chángpéi | 罗常培   |
| Sīmǎ Xiāngrú | 司马相如 |
| Zhào Píng’ān | 赵平安   |

复姓或双姓中，姓的部分连写，双姓之间是否加连接号视习惯而定。例如：

#### 5.1.2

复姓或双姓的人名，姓的部分连写，双姓之间加连接号，姓和名分写，姓的首字母大写，名的首字母大写。例如：

| 拼音              | 汉字     |
| ----------------- | -------- |
| Liú-Yǒng Fàn      | 刘永范   |
| Dōngfāng-Yuè Fēng | 东方岳峰 |
| Zhèng-Lǐ Shūfāng  | 郑李淑芳 |
| Xiàng-Sī Wénliáng | 项斯文良 |

#### 5.1.3

字、号、笔名、艺名、法名、技名、代称、帝王名号等，按人名的写法拼写。例如：

| 拼音         | 汉字（说明）           |
| ------------ | ---------------------- |
| Lǔ Xùn       | 鲁迅（笔名）           |
| Gài Jiàotiān | 盖叫天（艺名）         |
| Dù Gōngbù    | 杜工部（代称）         |
| Lài Tāngyuán | 赖汤圆（技名）         |
| Cáo Xuěqín   | 曹雪芹（“雪芹”为号）   |
| Lǔ Zhìshēn   | 鲁智深（“智深”为法名） |
| Wáng Tiěrén  | 王铁人（代称）         |
| Qín Shǐhuáng | 秦始皇（帝王名号）     |

#### 5.1.4

国际体育比赛等场合，人名可以缩写，可用全大写，名的首字母可大写，可省略调号和点号。例如：

| 全拼             | 缩写形式                         | 汉字     |
| ---------------- | -------------------------------- | -------- |
| Lǐ Xiǎolóng      | Lǐ X. L. 或 LI X. L.             | 李小龙   |
| Róng Guótuán     | Róng G. T. 或 RONG G. T.         | 容国团   |
| Zhūgě Zhìchéng   | Zhūgě Z. C. 或 ZHUGE Z. C.       | 诸葛志成 |
| Chén-Yán Ruòshuǐ | Chén-Yán R. S. 或 CHEN-YAN R. S. | 陈言若水 |

#### 5.1.5

中文信息处理及其他方面人名排序检索，可用大写姓，可省略调号。例如：

| 全拼              | 检索形式          | 汉字     |
| ----------------- | ----------------- | -------- |
| Zhāng Yǐng        | ZHANG Ying        | 张颖     |
| Wáng Jiànguó      | WANG Jianguo      | 王建国   |
| Shàngguān Xiǎoyuè | SHANGGUAN Xiaoyue | 上官晓月 |
| Chén-Fāng Yùméi   | CHEN-FANG Yumei   | 陈方玉梅 |

#### 5.1.6

全大写的人名拼写，姓和名部分均大写，双姓可加或不加连接号，可省略调号和分隔号。例如：

| 全拼            | 全大写形式     | 汉字     |
| --------------- | -------------- | -------- |
| Liú Chàng       | LIU CHANG      | 刘畅     |
| Zhōu Jiànjūn    | ZHOU JIANJUN   | 周建军   |
| Zhào-Lǐ Shūgāng | ZHAOLI SHUGANG | 赵李书刚 |
| Wú Xīng’ēn      | WU XINGEN      | 吴兴恩   |

#### 5.1.7

凡无法分解为姓和名、且音节在三音节及以上的名字，按专称形式连写，首字母大写。此类包括已词汇化的历史专称、笔名、艺名、法名、神仙名、帝王年号等。例如：

| 拼音         | 汉字（说明）     |
| ------------ | ---------------- |
| Kǒngzǐ       | 孔子（专称）     |
| Xīshī        | 西施（专称）     |
| Bīngxīn      | 冰心（笔名）     |
| Hóngxiànnǚ   | 红线女（艺名）   |
| Nézhā        | 哪吒（神仙名）   |
| Bāogōng      | 包公（专称）     |
| Mèngchángjūn | 孟尝君（专称）   |
| Liúshāhé     | 流沙河（笔名）   |
| Jiànzhēn     | 鉴真（法名）     |
| Qiánlóng     | 乾隆（帝王年号） |

#### 5.1.8

凡无法分解为姓和名、且音节在四音节及以上的名字，按语义结构或语音节段分写，首字母大写。例如：

| 拼音              | 汉字（说明）             |
| ----------------- | ------------------------ |
| Dōngguō Xiānsheng | 东郭先生（代称）         |
| Liǔquán Jūshì     | 柳泉居士（雅号，蒲松龄） |
| Jiànhú Nǚxiá      | 鉴湖女侠（雅号，秋瑾）   |
| Tàibái Jīnxīng    | 太白金星（神仙名）       |

### 5.2　少数民族语人名拼写规则

#### 5.2.1

少数民族语人名，按照该民族语的音位系统转写，按该民族习惯的顺序分写。转写方法可依国家公布的相关规定。

#### 5.2.2

在某些场合，可在转写的少数民族语原名之后，附上音译汉语人名的拼音和汉字；也可先写拼音和汉字，再附上转写。例如：

- Uluhurh（乌兰夫，Wūlánfū）
- Ngapoi Ngawang Jigme（阿沛·阿旺晋美，Āpèi Āwàngjìnměi）
- Seypidi（赛福鼎，Sàifúdǐng）

## 6　特殊问题的变通处理办法

### 6.1

出版物中常见的下列人名，其原有的拉丁字母拼写形式，凡约定俗成、习用既久的，可继续沿用；必要时可加括注或脚注说明：

- 历史人物；
- 港澳台人士；
- 华侨和外籍华人；
- 动物学、植物学、微生物学、古生物学等学科中文命名中出现的汉语人名。

### 6.2

根据实际需要，在护照、商标、外事文件、图书期刊等必要场合，大写字母 Ü 可写作 YU。例如：

- Lǚ Hépíng → LYU HEPING（吕和平）
