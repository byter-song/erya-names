# 尔雅起名个人使用指南

## 一个页面完成初选

「灵感池」保存生成过的名字，方便隔天继续。新生成的名字不会自动进入「我的候选」。收藏是你主动确认“值得认真考虑”的动作；只有保留的名字才提供评分和对比操作。「暂不考虑」保存理由，可恢复到灵感池。

可以生成多批，系统按同一方案的完整姓名去重。24/48/96 表示目标数量；指定字过多、避字冲突、单字名用尽时会返回较少结果并解释。典故优先表示先取当前符合条件的古籍名字，不足时以现代组合补足，不保证每批都是典故。

搜索支持名字、拼音和简要寓意。来源、使用提示、风格、评分排序和当前阶段保存在浏览器会话中。名字列表分段显示，避免候选多时页面卡顿。

## 随时修改条件

打开「起名条件与民俗设置」，或侧栏「起名条件」。可以调整姓氏、姓氏读音、一/二字名、风格和书写偏好。

- `知`：名字包含“知”，位置不限。
- `知:1`：名字首字固定为“知”；`知:2`：末字固定。
- `知:1、宁:2`：同时固定两字。指定字与避字冲突时不能保存。
- 避字可连续输入或用顿号分隔；亲属姓名按完整姓名排除；禁用组合填写不含姓的名字。
- 姓氏读音可人工修改，例如 `shàn`。复姓用空格分开，如 `ōu yáng`。

条件保存后用于下一批；历史名字、来源和生成时评分保留。更换姓氏后，旧名字仍是旧姓氏的历史记录，不会静默改名。现代组合与风格是编辑性建议；分数不是姓名的客观等级。

## 阅读名字详情

「释名与民俗」包含逐字释义、常见读音、简体笔画、真实引用原句、同句取字或连续取词的区别、全名声调、日常试读、文化背景与使用提示。

古籍引用保留作品和篇章链接。诗句中可能包含送别、征役、忧思、讽刺或祭歌语境；取意时应理解上下文。现代组合明确按字义说明，不会被包装成诗词原句。

重名人数、全国登记状态、方言语音没有在线数据支持。最终决定前请家人用普通话和常用方言试读，手写全名，并向当地户籍机关确认特殊姓氏或生僻字的登记要求。

## 民俗内容

民俗默认关闭，可以在建档时开启，也可以之后启用。民俗是传统文化参考，不是科学结论。

- 支持 1900–2100 年的有效公历日期，中国标准时间 UTC+8。
- 生肖同时列出“农历正月初一换年”和“四柱立春交节换年”两种口径。年柱按立春，月柱按节令，避免混用农历月份。
- 换日可选择 00:00 午夜或 23:00 晚子时。不同口径会影响部分四柱，需与家人采用的流派一致。
- 不知道时辰时勾选「时辰不详」，只显示三柱；不会编造时柱。节气交接当天的月、年柱仍可能有不确定性。
- 五行图是天干与地支本气的等权计数；藏干和纳音另列，不与图表相加。数量不能用来自动推断旺衰或喜用神。
- 家人可以自行指定五行意象，并决定是否纳入软排序。字义五行仅对自然意象明确的字归类；玉、锦等不因偏旁强行定五行。
- 五格在名字详情内演算：显示逐字笔画与公式。默认预填简体笔画；采用康熙口径时自行核对并修改。本工具不提供数理吉凶表。
- 不做真太阳时、历史夏令时或出生地修正；时辰和节气边界附近应核对出生记录。

## 对比、定稿与导出

在「我的候选」给名字评分、写下心选理由，并加入对比。对比池最多 5 个名字，可保存包含当时评分和来源的快照。选择 3–5 个最终候选后，选定最喜欢的一名并填写决定理由。

报告含原句、逐字解释、音律与选定理由。民俗启用时可附加出生时序和字义五行。勾选隐藏出生信息会同时隐藏可反推出出生信息的四柱报告；隐藏民俗会去除民俗解释。浏览器「打印或保存 PDF」可将报告保存到本地。

## 数据在哪里

所有个人方案在浏览器 IndexedDB 中。清理网站数据、使用隐私窗口、换浏览器/端口或设备都会影响可见数据；关闭普通窗口后再次用相同地址打开，数据仍在。

定期到「备份与导出」下载 JSON 或密码加密备份。加密使用浏览器 Web Crypto，密码不存储；请自行保存密码。恢复先校验文件并显示预览，确认前不写数据库；可选择导入副本来保留两个方案。

不要把备份当作匿名文件，它包含家庭条件。页面不上传这些信息。来源链接只有主动点击才会打开外站。

## 本机运行与更新

运行 `make dev` 后使用 `http://127.0.0.1:5173`。推荐长期固定此地址。要体验构建版运行 `make build` 和 `make preview`，并通过备份将方案迁移到 `http://127.0.0.1:4173`。

更新前备份；旧候选链接会进入同一选名工作台。应用资源和语料分开发布，语料 URL 包含内容哈希。语料载入失败会显示重试入口，不会清空已有方案。
