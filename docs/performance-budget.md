# 性能预算

本预算以 0.3.0 个人版构建为当前基线。预算只允许通过评审后收紧；若需放宽，必须记录真实用户场景、测量报告与原因。

| 指标                       |             门槛 | 说明                                                              |
| -------------------------- | ---------------: | ----------------------------------------------------------------- |
| 首屏 JavaScript raw / gzip | 1.05 MB / 350 kB | 包含入口、立即启动的 bootstrap 及其静态依赖；不含按路由加载的页面 |
| 民俗规则包 raw / gzip      |   100 kB / 25 kB | 独立动态规则文档总量；任何规则文档不得进入首屏依赖图              |
| CSS raw / gzip             |   140 kB / 50 kB | 包含黑金宣纸视觉、响应式导航和页面交互样式                        |
| 字体资源总量               |              0 B | 全站使用系统字体，不发布 Web 字体                                 |
| 数据 raw / gzip            |  1.3 MB / 220 kB | 包含 396 条典故、8,105 字拼音、繁简映射和字义五行                 |
| 项目打开 P95               |         1,000 ms | 本地 IndexedDB、1,000 候选基准                                    |
| 生成一批候选 P95           |         2,000 ms | 当前每批固定 9 个；正式发布需在 production bundle 验证            |
| 1,000 候选筛选 P95         |           100 ms | 从输入到 DOM 稳定                                                 |

`npm run quality:bundle` 输出 `output/performance/bundle-budget.json`。浏览器运行时报告由 `tests/e2e/ui-performance.spec.ts` 生成。

新方案默认采用“民俗核心”预设，但规则文档仍在首次实际评分时按需加载，不阻塞方案中心的首次可用时间。报告记录全部 JS 总量，发布门禁分别约束首屏依赖图和独立规则包；缺少出生信息或用户尚未确认采用五行时，对应维度返回 unknown 并退出分母，不会静默关闭模块。

2026-09-18 金线水墨交互重设计基线：JavaScript 约 957 kB / gzip 314 kB，CSS 约 33 kB / gzip 8 kB，字体资源 0；生成 P95 约 1423ms，1,000+ 候选打开 P95 约 131ms，筛选 P95 约 52ms；Lighthouse Performance 93、Accessibility 100、Best Practices 100。

2026-09-29 黑金水墨山水基线：JavaScript 约 1008 kB / gzip 343 kB，CSS 约 41 kB / gzip 13 kB，字体资源 0，原创 SVG 山水主景约 9.2 kB；48 名生成 P95 约 1305ms，1,000+ 候选打开 P95 约 148ms，筛选 P95 约 21.3ms；Lighthouse Performance 95、Accessibility 100、Best Practices 100。Canvas 首屏先绘静态墨晕，指针交互立即启动动态，环境动画延后启动并限制约 30 FPS；DPR 上限 1.5、动态粒子上限 120。

2026-10-16 长卷重构基线：全站统一使用系统字体，不发布 Web 字体；移除运行时山水 SVG、双 Canvas、指针监听、导航过渡、持续环境动画和设计原型静态资源；侧栏与方案恢复使用客户端路由，启动页只反映真实资料加载状态。发布检查的当前体积和 Lighthouse 数据以同次 `make release-check` 产物为准。

2026-09-30 语料扩充后，运行时数据包含 396 条双字典故、覆盖 8,105 个规范字的拼音索引、4,148 条繁转简映射，以及 303 张字卡的可解释五行文化意象。数据资源实测约 1.24 MB raw / 210 kB gzip；为完整保留来源、释义和文化意象证据，将 data raw 门槛调整为 1.3 MB，同时保持更能反映网络传输成本的 gzip 门槛 220 kB 不变。索引不会扩大 303 张自动生成字卡的可生成范围。
