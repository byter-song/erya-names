# 现代组合候选编辑与校验记录

初版日期：2026-09-27；扩容复核：2026-10-15。

当前交付为 **600 条二字现代组合名**，数据文件为
[`modern-combinations.json`](../../src/data/curated/modern-combinations.json)。每条包含针对整名独立撰写的组合取意、日常使用提醒、1–2 个风格标签和表达风格取向。

**全部内容由 AI 编辑并进行结构与边界校验，未经过专家逐条人审。** 此记录不构成人工审定证明，不提升为 production 人审状态，也不代替家庭对实际姓名的选择与核查。

## 内容与来源边界

- 用字限定于 [`personal-bundle.json`](../../src/data/curated/personal-bundle.json) 的 303 个字，最终实际使用其中 **228 个不同汉字**。未新增字卡，也未为了覆盖字表而使用不适合的概念字。
- 对照该包 396 条典故来源记录，排除全部 **369 个唯一 `selectedText`**。
- 参考初版编辑名单后重新取舍（已由本结构化组合库替代），逐条编辑解释和提醒；没有按两两笛卡尔积自动填满数量。
- 所有解释均为本次现代组合取意，不提供古籍引文或虚构篇名。这里的“现代组合”说明本条解释的形成方式，**不声称这两个字在历史文献中从未相邻出现，也不声称名字由本项目首次创造**。
- 美玉、草木、山川、日光等作为审美意象；承诺、包容、求知等作为家庭期许。没有把这些意象写成孩子性格、健康、事业或人生结果的保证。
- 编辑和校验没有读取、上传或写入家庭姓名、出生信息或其他个人资料。

最常使用的字是“宁”，出现于 28 个名字，占候选的 4.7%；其后为“清”25 次、“嘉”23 次、“月”和“安”各 21 次。没有靠单个首字或尾字铺满 600 条，也没有以倒序翻转制造重复选择。

按字卡的首选普通话读音作静态比较，存在 **47 个普通话同音组**，每组最多 5 个不同写法。例如“书悦／舒悦／姝悦／纾悦／舒月”保留不同的字义、书写和风格选择。600 条是 600 个不同文字组合，不是 600 种不同读音。此比较不覆盖方言、轻声、全名连读和所有多音变体，不能据此宣称无谐音风险。

## 本轮取舍实例

以下说明实际编辑中放弃的项及原因，不代表对同名个人作评价。

| 放弃的项               | 原因与处理                                                         |
| ---------------------- | ------------------------------------------------------------------ |
| 云霁、星野             | 旧名单中的“霁”“野”不在当前 303 字内，改为“云溪”“星朗”并重写解释    |
| 晴初、溪言             | 分别与已保留的“初晴”“言溪”构成倒序对，改为“晴珞”“溪遥”             |
| 雅宜                   | 与“牙医”同音，改为“雅蓁”，同时明确蓁字读音和解释成本               |
| 时屿                   | 与“食欲”同音，改为“时煦”                                           |
| 逸达                   | 与常见品牌“益达”同音，改为“逸珩”                                   |
| 初禾                   | “锄禾”联想较强，改为“初楠”                                         |
| 卉妍                   | “讳言”联想不利于日常使用，改为“卉琳”                               |
| 澜庭、砚庭、岩庭       | 本轮读感更偏场所或书斋题名，改为“澜心”“砚秋”“岩修”                 |
| 可融                   | 动词短语感偏强，改为“嘉融”                                         |
| 知止、修身、格物、慎独 | 不作为补足数量的候选；这些概念词不符合本轮优先自然姓名感的编辑方向 |

保留部分自然使用的词语型名字，如“初晴”“良辰”“允诺”，也保留不同字义的同音写法。取舍依据是整体姓名使用感，不是把所有词语、地名或熟悉读音机械排除。对“洛宁”“兰溪”“南音”等已有地名或文化类别联想，提醒中已写明。

## 家庭仍需核查的边界

1. 加上真实姓氏、家族字辈后，检查普通话及常用方言的连读、谐音、重音和拆分方式；本文件只有二字名字，没有姓氏前缀。
2. 统一多音字的姓名读法，尤其“予、宁、乐、柏、珩”等，并实际练习电话报姓名、手写与输入。
3. 分别试用幼年昵称、学校点名与成年正式署名场景；温柔、清淡或古雅风格是否耐用，需要家庭自行判断。
4. 结合真实使用地区查询重名情况，检查家庭避字、亲属同名、文化和品牌联想；本次没有人口姓名数据库，也没有穷尽商标、人名或地方名称检索。
5. 字表成员校验不等于实际登记结果。最终登记用字、证件编码和录入要求，以当地办理口径为准。
6. 本记录的校验针对交付内容文件。运行时来源展示、筛选、去重与逐条实际生成的验证应由集成流程另行完成，不把静态校验冒充完整发布验收。

## 可复现的内容边界检查

在仓库根目录运行以下只读检查；不会加载家庭方案数据：

```python
import json
import re
from pathlib import Path

root = Path(".")
rows = json.loads(
    (root / "src/data/curated/modern-combinations.json").read_text()
)
bundle = json.loads(
    (root / "src/data/curated/personal-bundle.json").read_text()
)
allowed = {row["char"] for row in bundle["characters"]}
excluded = {row["selectedText"] for row in bundle["allusions"]}
names = [row["givenName"] for row in rows]
fields = {"givenName", "meaning", "styleTags", "usageNote", "genderExpression"}
styles = {"清朗自然", "文雅书卷", "沉稳端正", "中性现代", "温婉灵秀"}

assert len(rows) == len(set(names)) == 500
assert all(len(name) == 2 and set(name) <= allowed for name in names)
assert not set(names) & excluded
assert not any(name[::-1] in set(names) for name in names)
for row in rows:
    assert set(row) == fields
    assert 1 <= len(row["styleTags"]) <= 2
    assert len(row["styleTags"]) == len(set(row["styleTags"]))
    assert set(row["styleTags"]) <= styles
    assert row["genderExpression"] in {"neutral", "masculine", "feminine"}
    assert 20 <= len(re.findall(r"[\u4e00-\u9fff]", row["meaning"])) <= 45
    assert 10 <= len(re.findall(r"[\u4e00-\u9fff]", row["usageNote"])) <= 30
assert len({row["meaning"] for row in rows}) == 500
assert len({row["usageNote"] for row in rows}) == 500
print("PASS: 500 unique two-character modern combinations")
```
