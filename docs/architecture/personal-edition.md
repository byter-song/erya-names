# 个人版 0.3 的实现契约

## 选名记录

`inspiration`、`candidate`、`selected`、`excluded` 是唯一候选池状态。`excluded` 保存最近活跃池和排除原因，可恢复；精选池数量不限。

统一配置位于 `/projects/:id/config`，生成、筛选、详情、比较与四池操作位于 `/projects/:id/names`，精选导出位于 `/projects/:id/export`。保存影响评分的配置后，既有候选会异步重算。

## 内容包

个人包的字符与典故为 `source_checked`，与原有生产人审 `verified` 明确分离。`modernCombinations` 是个人包可选集合，每项包含组合名、独立整名取意、1–2 个风格、实际使用提醒和表达倾向；名字本身必须通过同一套规范字、家庭条件与语言规则。

现代组合只作为编辑推荐，没有伪造的古籍引用。组合取意写入候选 summary，使用提醒写入同一候选的 sourceEvidence，v2 备份完整保存。启用的民俗模块分别产生评分与证据，不能绕过基础硬条件。

`data:build-personal` 从仓内来源资料重建个人包，`data:audit` 检查哈希、用字、引用和许可；`quality:combinations` 对全部 600 个组合逐一调用真实生成器，核对名字、整名解释和使用提醒，并已纳入 `release:check`。

## 计算与性能

组合生成按固定种子遍历和抽样，避免构建所有两两组合的富对象数组。全名去重和历史排除在应用层执行；持久化事务内再检查一次指纹，防止两个窗口从相同历史生成后重复写入。

语料作为同源、带内容哈希的 JSON 发布。应用先加载并校验资料结构，再初始化路由；资料失败时保留重试与已有方案/备份入口，暂停生成。页面按路由按需加载；民俗历法计算随相关页面加载，避免首屏下载无关代码。

## 保存与导出

完整建档在单事务写入，评分与备注按操作顺序持久化，避免前一次保存覆盖新内容。候选详情使用可关闭、焦点可恢复的模态框。分享版精选导出严格隐藏出生、四柱、亲属、生肖细节与备注；个人版必须二次确认。

## 民俗口径

中国标准时间 UTC+8；公历 1900–2100；不做真太阳时或历史夏令时修正。可选午夜/晚子时换日，时辰不详时只显示三柱。表层五行计数、藏干、纳音和名字字义意象分开展示，避免混算。五格只按明确笔画演算公式，不输出吉凶或人生预测。

## 长卷环境

环境层不加载山水图片，由 CSS 宣纸纹理、圆轨和静态墨色构成。应用挂载后不注册视觉用途的 `pointermove` 或 `pointerdown` 监听，不渲染持续 Canvas，也不提供动效开关。

启动阶段显示“展卷寻名”结构，数据和应用代码准备完成后由 React 根节点替换，不增加固定等待；`prefers-reduced-motion` 下关闭进度动画。屏幕品牌字、标题、正文与打印统一使用系统字体。

视觉只保留纸墨金线主题，不保留旧主题切换与兼容样式；章节导航不触发路由级页面进入动画。
