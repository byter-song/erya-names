# 语料准入与候选评分

## 两套分数的边界

尔雅起名使用两套相互独立、可解释的分数：

1. **语料准入分**决定一条精选典故能否进入个人数据包。
2. **系统匹配分**决定已通过 L1/L2 门禁的候选如何按当前家庭偏好排序。

分数不表示名字、人物或人生的客观优劣。用户自己的 1–5 分始终单独保存。

## 持久精选语料

处理后的双字精选记录是版本化输入，位于：

- `data/sources/personal/allusions.tsv`：既有精选。
- `data/sources/personal/s-allusions.tsv`：S 级固定来源扩充。
- `data/sources/personal/a-allusions.tsv`：A 级新典籍扩充。
- 同名 `*-anthology-evidence.json`：逐条来源、原句、版本和定位证据。

`npm run data:build-personal` 直接消费这些文件，不会从原始大语料重新生成名字。
`data/cache/` 和 `data/normalized/` 只服务来源核对与候选研究，可以安全重建。

通用拼音索引独立保存在 `data/sources/personal/standard-character-pinyin.json`，当前覆盖
《通用规范汉字表》8,105 字。索引用于手工录入和读音展示；只有 303 张已复核字卡可参与
自动生成，不能因为存在拼音就绕过字义、使用风险和内容审核。

固定底本可以保留繁体原文；`traditional-to-simplified.json` 持久保存 4,148 条单字映射。
精选构建和运行时候选在字卡检查前逐 code point 转换，页面使用的名字、作品、篇章、原句、
释义和提醒均为简体。这样不会因上游繁体造成候选损失，同时仍可通过固定来源链接核对底本。

## 语料准入分

模型版本为 `corpus-score-1`，满分 100，准入线 70。以下信息只扣分、不加分：

| 扣分项         | 规则                                     |
| -------------- | ---------------------------------------- |
| 上下文风险     | `low: 0`、`medium: -10`、`high: -24`     |
| 释义清晰度     | 每低于 5 级扣 4 分                       |
| 现代姓名可用性 | 每低于 5 级扣 3 分                       |
| 多音字         | 每个扣 4 分，最多扣 12 分                |
| 书写复杂度     | 最大笔画超过 16 扣 2 分，超过 20 扣 5 分 |
| 单字取名       | 扣 3 分；当前精选包实际全部为双字        |

原句不匹配、取字顺序错误、缺少规范字/拼音证据属于构建错误，不进入数值补偿。
构建产物为每条典故保存 `corpusScore.total`、准入线、模型版本和扣分明细；低于准入线时整个构建失败。

## 系统匹配分

模型版本为 `system-score-1`。每个候选持久化 `l3-score-base: +60`，再叠加当前规则产生的正负 `scoreDelta`，最终统一截断到 `0–100`。

- L1/L2 `reject` 先淘汰，不能被加分抵消。
- 风格匹配、来源证据、读音、声调、书写、表达偏好和可选 L4 民俗项提供显式增减分。
- 风格不匹配、重复音节、复杂书写、已知全名谐音和语料上下文折损会形成显式负分。
- `full-name-2` 将谐音扣分写入规则记录；旧 `full-name-1` 读取时兼容为一次 `-8`，不再存在排序暗扣。
- L4 只有用户明确开启并允许参与排序时生效，仍需展示“传统民俗参考，非科学结论”。

生成排序、IndexedDB 读取、候选卡、详情和对比页均从同一组版本化 `ruleResults` 聚合，避免历史候选被当前规则重算。

## 历史用名

`personUsages` 只按完整姓名精确匹配，展示历史人物或科举人物的中性使用事实。当前包含 5 条历史人物和 61 条科举人物记录，其中状元、榜眼、探花各 15 条，进士 16 条。它不进入 `sourceType`、`ruleResults`、系统匹配分或排序；四种科举身份必须使用独立枚举及明确名次证据。

全部 303 张生成字卡均由 `character-elements.json` 提供五行文化意象。分类优先使用当前字卡的字义和可解释自然、材质、时序或品格意象，字形只作辅助；不采用读音五行或笔画数理一刀切。每字保留独立理由、方法版本、日期和来源引用，并统一标注为传统民俗参考。

## 发布边界

当前扩充内容属于 `personal/source_checked`，可以进入个人包，但不等于 production 人审通过。公共 production 仍要求真实主审、高风险双审、普通记录抽样双审及现有数量门槛。
