# 尔雅起名 0.3 个人版交付记录

日期：2026-09-27。使用入口与启动步骤见 [README](../README.md)。

## 实际交付

- 生成与筛选同页；每批固定 9 个且界面不提示数量选择；主动收入后才计入候选。
- 单一纸墨金线长卷视觉；桌面与移动端共享章节导航，路由切换无强制页面过渡。正文、标题、表单与打印统一使用系统字体；环境层由 CSS 宣纸、圆轨和静态墨色构成，不加载山水图片、不响应鼠标轨迹或点击泼墨。
- 303 个用字、396 条经过准入评分的双字典故、600 个现代组合名，以及 81 条历史用名参考；其中 30 条状元记录只作灵感来源，不参与评分。
- 组合寓意、字义、读音、书写、出处和使用提醒；四柱、节气、藏干、纳音、五行、生肖口径及五格演算。
- 统一配置中心、透明多维评分、候选详情、只读横向比较、精选名单 JSON/PDF 导出，以及 JSON/加密备份恢复。
- 灵感池、候选池、精选池、排除区构成唯一筛选状态机；选择/移除逐项持久化，排除项可恢复或确认后永久清理。
- 全新 v2 数据库和严格 v2 备份契约，不包含旧迁移、旧定稿、旧报告或旧比较快照格式。

## 验证证据

- 本地验证以 `make release-check`、`npm run test:coverage` 和当前 CI 输出为准；`output/` 是可重建且不入库的本地产物，不作为长期信源。
- 测试数量会随语料扩展和体验修复变化，不在交付文档中固化旧快照。
- 桌面 Chromium / WebKit 与移动 Chrome / WebKit 分开验证，覆盖核心旅程、可访问性、移动导航和性能门槛。
- 600 / 600 组合逐条调用实际生成器，名字、寓意、使用提醒完全对应，失败 0。报告 `output/quality/modern-combinations.json`。
- Lighthouse 与性能数值以最新 `output/lighthouse/`、`output/performance/` 报告为准；这些报告为本地生成证据。
- 依赖审计 0 vulnerabilities；安全扫描、字体/JS/数据体积预算均通过。
- 390px/430px 移动端除页面宽度外，还自动验证当前旅程步骤处于底栏可视区域；打印报告需继续做渲染核验。

## 构建与边界

最终静态产物在 `dist/`；manifest 在 `output/release/release-manifest.json`，已通过 `release:verify`。后续源码或语料修改须重新构建与验证；不得将旧验证结果套在新构建上。

本版本是个人本地版。起名资料经来源核对与 AI 编辑，不冒充专家逐条人审。民俗是文化参考，不自动判喜用神、不预测命运。公共 production 人审语料、Edge 和远端发布验收仍是独立步骤，详情见 [发布检查](release-checklist.md)。

500 组合内容由子 agent 编辑，主 agent 完成接入与全量生成校验；数据包括 228 个实际用字、262 个中性表达、114 个偏阳刚表达、124 个偏柔美表达。风格标签只是审美取向，不限制任何性别使用。
